Problema seleccionado: Registro de notas de un curso
Descripción
Este programa permite registrar las notas de un grupo de estudiantes.

Cada nota debe encontrarse entre 0 y 100. El programa clasifica a cada estudiante como aprobado o reprobado, calcula el promedio general y permite registrar un máximo de 30 estudiantes.

Reglas del programa
Nota mínima permitida: 0
Nota máxima permitida: 100
Nota mínima de aprobación: 70
Cantidad máxima de estudiantes: 30
Las notas inválidas no se cuentan ni se agregan al promedio.
Si no se ingresan notas válidas, el programa muestra una advertencia.
